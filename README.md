# gmc-cost

Astro site for Plum's group health insurance cost guide (India, 2026).

```bash
npm install
npm run dev
```

The page uses licensed GT Alpina and Passenger Sans fonts, which are not committed. Copy the font files into `public/fonts/` locally (or into your host's asset storage); otherwise the page falls back to Fraunces and Mulish from Google Fonts.
